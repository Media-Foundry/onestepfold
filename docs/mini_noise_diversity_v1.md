# C4/S1 训练噪声多样化对照 v1

用户要求探索其他改进方向后，由TRAIN32新噪声诊断触发；不再增加全局损失权重。
诊断中weak相对retained的AA收益：已见两噪声+0.002791，新四噪声+0.001356；
新减旧收益−0.001435，蛋白bootstrap95%CI[−0.002802,−0.000221]。
这支持有界训练试验，不证明噪声记忆是唯一原因。新噪声也已成为开发诊断信息。

## 唯一训练变量

两臂fixed/diverse，从同retained512出发，423条TRAIN、相同有序8192曝光、2048更新、
累积4、原Adam/LR/裁剪、相同weak损失与权重、冻结ESM2/C4、原生C4/S1/K1。
fixed沿用旧600001/600011；diverse第i次曝光用1800000+i，每次曝光独立固定初始噪声。
蛋白及epoch顺序一字不变；不改变GT、mask、化学、参数范围或加入对称原子训练。
源码中legacy training_seeds字段保留用于预检/固定TRAIN探针，实际训练噪声以orders为准。
诊断920003/920009/920021/920033不参与两臂训练。无DEV读取、checkpoint选择或额外曝光。

## 同平台教师与控制

两臂的辅助teacher都是相同public Mini C4/S2、匹配同一初始噪声，GT仍为实验坐标。
为避免只改变新噪声臂的教师平台，fixed的846份旧噪声teacher也在ROCm重新生成，
另生成8192份新噪声teacher；共9038份、18076次denoiser调用，缓存只生成一次。
因此需要新fixed控制训练，而不能把旧CUDA teacher训练的weak当唯一因果对照。
原先weak保留作背景；不得称两次fixed完全同一训练，教师缓存平台已显式改变。
原条件缓存和GT标签复用并校验，不调用ESM或Pairformer，不修改旧缓存。

8GCD分配教师缓存；全部教师有限、哈希与输入身份核验后，fixed用GCD0，diverse用GCD2。
先分别做两条原工程输入的public重放、参数梯度和重复加载预检；全初始指纹应相同。
预检通过后仅运行锁定的2048更新。每进程4小时上限，失败保留，无自动重试/扩大预算。
双方初始TRAIN32×2探针必须精确相同，其他探针仍只用于记录，不做提前选择。

终点须审计实际噪声订单、损失、参数与优化器状态，再评价固定455×2原面板，
并另报原TRAIN32四枚诊断新噪声。原DEV32及已揭晓噪声均不是全新独立确认。
质量、全链误差、退化尾部、几何和成本分别报告。推理冻结参数状态与训练探针的
requires_grad状态分开记录；做匹配状态重放，不重演跨状态逐位检查的已知混淆。
本轮不自动晋升模型；无BindCraft、输出修复、ESMC桥接或方法组合。
