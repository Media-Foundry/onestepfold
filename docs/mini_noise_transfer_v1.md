# C4/S1 固定噪声记忆诊断 v1

在新预测前冻结；不训练、不改变任何历史评分。本轮比较retained512起点与已完成weak
终点，固定原TRAIN32（不按新结果挑选），C4/S1/K1、原生FP32、同一冻结ESM2/C4缓存。
两枚已见噪声600001/600011与四枚新噪声920003/920009/920021/920033分别比较。
32×6×2=384次预测，8GCD分片，另56次既有工程检查。全部参数requires_grad=False。
weak旧噪声64份必须精确复现上一轮冻结评估；不与requires_grad=True训练探针混比。

复用原始GT/mask/评分，逐噪声及蛋白均值报告质量、几何与RMSD。
主要诊断是(weak−retained)在新噪声与已见噪声的差，bootstrap单位仍为蛋白，
不是把192个噪声实例当成192条独立蛋白。两个噪声集合大小不同，报告条件范围，
不做best-of-seed。无DEV读取、无新checkpoint选择、无自动重试或追加噪声。

如果收益在新噪声下消失，支持下一步单独测试训练噪声多样化；若两组噪声收益相近，
不因“只训练两枚噪声”就认定过拟合。它不能认证未见序列泛化或所有噪声分布。
本轮只建立是否值得改训练采样的证据，不按结果自动启动大训练。
