# Pairformer 路径精度诊断：选中输入编码／初始化段，局部 AD 获得一致性证据

2026-09-28。按预先锁定的 control、方向 2、h=.003 选择，最大粗分段偏差位于**输入编码与初始化**，并非某一轮 recycle。本轮只对该段追加原三个方向／五个步长的精度干预；没有运行 diffusion、增加目标／α 或训练模型。

## 完整跨轮状态已验证，没有把复用输入冻结成基点值

边界为完整早期接口，然后输入初始化、recycle1–4。跨轮状态包含 s、z、s_init、z_init、s_inputs，以及 ESM 输出、restype 和五类原始参考化学字段。profile 按原代码与 restype 绑定；需要的参考原子对派生量重新生成。所有实际 u0/u+/u− 分别保存，初始化量在正负端点间保持其真实差异。

本机实际配置：MSA module **1 block**、template 0 block、Pairformer 16 blocks。不能因无外部 MSA 输入就假定 MSA module 不执行。实际读取记录覆盖 msa/profile/deletion 特征、s_inputs 和原子／残基信息；没有发现遗漏的可微字段。

采用逐段独立切断的 VJP 递推，避免对有祖先依赖的 s/z 与初始化量直接取总导数而重复计入贡献。验证结果：

- 分段前向、原生完整四轮前向、旧归档基点输出逐位一致。
- 15 组最终完整接口差分与旧归档逐位一致。
- 逐段回传的早期输入 VJP，与原始四轮路径直接 VJP 及旧归档均逐位一致，重建误差为零。
- 选中段的局部 VJP 与粗分解边界 VJP 也逐位一致。

## 冻结实际端点的三项精度分解

依然使用相同 μ 和 v_h=(u+−u−)/(2h)。这里 v_h 是中间扩展状态方向，不能与原始 logits 方向混为一谈。

主行：

| 计算 | 响应 |
|---|---:|
| 原生 FP32 secant S32 | +6.6300129e−3 |
| 原生 FP32 AD A32 | +5.0566966e−4 |
| 参考 FP64 secant S64 | +5.0566734e−4 |
| 参考 FP64 AD A64 | +5.0566735e−4 |

| 分解项 | 数值 |
|---|---:|
| 原生差异 S32−A32 | +6.1243432e−3 |
| 前向 secant 精度差 S32−S64 | +6.1243455e−3 |
| 高精度有限端点余项 S64−A64 | −8.26861e−12 |
| 局部 AD 精度差 A64−A32 | −2.31383e−9 |

15 行中，前向 secant 精度差均主导。原生差异绝对值为 1.32e−5～6.12e−3；高精度有限端点余项为 1.35e−13～8.27e−12；局部 AD 精度差为 1.80e−11～2.31e−9。

最大相对差：

| 比较 | 最大相对差 |
|---|---:|
| FP32 AD / FP64 AD | 4.58e−6（约 0.000458%） |
| FP64 secant / FP64 AD | 1.20e−7（约 0.000012%） |
| FP64 true JVP / VJP | 4.69e−14 |

参考 FP32 的 true JVP/VJP 也在全部 15 行支持，最大相对差 3.80e−5。没有以 backward-of-backward 替代前向模式。

主行中点偏移范数 2.42909e−4，最大端点半径 2.85388e−4，都是中间张量未归一化范数。非对称端点被完整保留，高精度余项不命名为纯曲率。原生分子尺度偏差 2h(S32−A32)=3.67461e−5，对应高精度余项分子仅约 −4.96e−14。

## 参考实现与实际 dtype 核查

原生规范化走 OpenFoldLayerNorm/PyTorch 路径，未替换 LayerNorm 定义或 epsilon。参考复制同一 FP32 权重并精确升精度；原生模型不改动。

实际 Protenix primitives attention 显式把 q/k/bias 转 FP32。独立 FP64 参考移除此处降精度，保持 attention 的 scale、bias、mask 定义；参考 FP32 仍走原生函数。另有 Linear.precision 固定精度属性，仅在参考副本中随参考 dtype 提升，所选初始化段相关项包括 ref_pos 和 d 的投影。其他未执行模块的副本属性虽一起复制／升精度，但没有调用 diffusion。

- 参考 FP32 与原生 FP32 的基点、全部正负端点及 AD 投影均完全一致。
- FP64 参考记录到的 558 个浮点算子输出全为 FP64，三次 attention 调用输入／输出均为 FP64，未发现显式 FP32 中间输出。
- 参考副本关闭 checkpoint 包装以支持 true JVP；FP32 对照验证此执行变化未改变所测结果。
- 上述审计检查可观察算子的张量 dtype，不声称审计所有 GPU 内部指令；前向精度差仍指这组匹配参考实现下的精度干预结果，不指认某个坏 kernel。
