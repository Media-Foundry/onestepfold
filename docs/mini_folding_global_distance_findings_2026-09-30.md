# C4/S1 全局距离监督：固定终点结果

**长程距离监督减轻了距离低估，基本保住去坐标项后的局部精度；但只追回少量整体
RMSD，仍未解决局部／全局取舍。保留此候选，不替换当前研究参照。** 本轮训练与
完整评估已结束，没有追加权重网格或延长训练，也没有恢复 BindCraft、突变或修复支线。

## 固定比较与证据范围

预训练 Mini-ESM，冻结 ESM2 与 C4，只更新 diffusion；推理保持原生 FP32、
C4/S1/K1。三种 TRAIN423 配方使用相同 retained512 起点、样本顺序、噪声、优化器、
2048 次更新及 8192 次曝光。新候选在 coordinate_zero 上增加实验 GT Cα 距离监督：
同链序列间隔≥24，无空间距离上限，SmoothL1 beta=10 Å，固定权重 0.03290655679814053。
权重由 TRAIN32 初始坐标梯度预算校准；没有用 DEV 选权重。S2 辅助监督是预测，不是 GT。

455 条蛋白×两枚固定噪声×六模型，共 **5460 份评分**。复用4550份参照，新增910次
候选预测及32次工程调用。TRAIN128、新增TRAIN295和已观察DEV32分别汇总；每个蛋白
先平均两枚噪声，不选最佳噪声或中间checkpoint。DEV32未参与训练，但已经参与多轮
方法判断，不再是新独立确认。来源多为同源多聚体中的完整单链，不能声称无预训练暴露。

## 方法判断与下一步

1. 保留三种配方及固定终点，不提升新模型为默认、不延长本批、不把旧DEV重新命名为
   独立确认。原生S2仍是质量参照，部署仍要求S1。
2. 新监督缓解了距离低估，但当前校准强度／监督形式没有替代原坐标项的全局作用。
   下一项应先在**已有TRAIN**上核对新项沿途的损失与梯度预算，区分作用过弱、与
   其他目标竞争、以及Cα距离与整体坐标约束的差异；不凭DEV挑一个更大权重，也不
   自动开启多权重矩阵。这是待做分析，不是本批已经证实的原因。
3. 用户建议的ESMC已单独测试：固定仿射接口DEV AA下降0.042589，故当前继续ESM2。
   这不能外推为ESMC本身更差；进一步结构适配应是独立候选，不能混入本轮损失比较。
4. 当前有效训练规模仍是423，不是29.7k；数据规模、接口和监督三个轴不同时改变。
   主线始终是保留预训练能力、改进C4/S1硬输入折叠，尚未进入BindCraft集成。
