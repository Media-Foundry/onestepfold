# 一步 diffusion 适配器工程预检完成，尚无训练效用结论

本轮把下一阶段所需的可训练路径实际跑通：冻结原生Mini，只给token diffusion
Transformer加入可合并的低秩权重更新。一次实验GT＋S2监督的反向更新、checkpoint
重放及合并全部成功。最终仍一次diffusion调用，没有外接坐标修复器。
**这是一项工程结果，不是“一步质量已追回”或“设计模型已可部署”。**

## 数据与执行范围

使用1U07，90残基、710重原子、噪声500009。它是前一来源池中唯一通过完整原生
化学/GT映射、却未进入fresh8模型评估的候选。复核父清单哈希、原有历史隔离及对
fresh8的PDB/accession/序列HSP隔离后才开始。此后它属于开发/训练预检数据，不能
再当独立验证。没有读取2B0A、2Z0J或原32条的坐标来训练。

固定[事前协议](mini_diffusion_adapter_preflight_v1.md)：原生FP32 ESM2-3B＋Mini，
四轮recycle，身份绑定噪声，确定性S1/S2规则。先生成未修改模型的S1及S2，再安装
适配器。S2仅是合成参照，GT仍来自原实验结构。只做一次AdamW更新，无重试、搜索、
多checkpoint择优或延长训练。Pairformer conditioning在本工程预检中缓存，不能
把这称为完整序列训练或输入梯度验证。

## 得到实际验证的工程条件

| 项目 | 结果 |

| 新可训练参数 | 835,584，112个张量 |
| 原模型参数 | 1613个原参数张量逐位保持；均未接收梯度 |

| 模型调用 | Pairformer4次、diffusion10次，含2次教师调用及各项重放 |

适配器在训练时通过权重参数化参与原生模块计算，合并后不再需要执行低秩矩阵乘法；
本次已核验合并坐标，但没有做完整推理延迟基准。没有修改公开基础checkpoint文件。
新增机制使用[PyTorch参数化接口](https://github.com/pytorch/pytorch/blob/main/torch/nn/utils/parametrize.py)，
运行环境与实际重放比文档推断更重要：本次torch为2.12.0a0+git78258b9。

conditioning三个VJP范数为0.0152894、0.00977881、0.0164325。
它们只证明本点合并后的模型对连续conditioning仍有非零梯度，不是对完整soft
sequence、跨原子图突变或整个Jacobian的认证。

## 更新量很小，不能包装成方法收益

预检目标是对S2及实验GT的等权、刚体对齐后全原子MSE。对应关系固定，没有做等价
侧链原子重命名；这不是正式训练配方或完整化学监督。

| 指标 | 更新前S1 | 一次更新后S1 | 未修改S2参照 |
|---|---:|---:|---:|
| 对实验GT AA-lDDT | .841649829 | .841658023 | .842923409 |
| 严重碰撞（距离<1 Å） | 0 | 0 | 0 |
| 最大穿透 Å | 2.133642 | 2.133590 | 2.068093 |
| 键长RMSE Å | .203072 | .203079 | .198402 |
| 肽键MAE Å | .072883 | .072883 | .044244 |
| 所检Cα手性比例 | 1 | 1 | 1 |

AA仅增加约8.19e−6，不支持有效训练、泛化或离散设计收益。三个输出的最大穿透都
超过旧基础诊断的2 Å线，零严重碰撞不能替代更完整的化学检查。本轮没有认证全部
侧链立体中心，不能把表中的Cα比例扩成全面手性正确。

两项工程损失分别为：

- S2对齐MSE：0.09413743→0.09410215。
- GT对齐MSE：41.01328508→41.01094978。

S2项的参数梯度范数0.0767798，GT项1.039874，约相差13.54倍；夹角余弦0.292599。
总梯度裁剪前范数1.064874。这表明本点等权标量相加不等于监督贡献相等。**不据
这一个点反推一个“最佳蒸馏权重”**；后续训练须在训练数据上预先规定监督尺度和
化学目标，并保留各项梯度/质量记录。没有在预检后追加更新来追求更大涨幅。

## 成本、复算与限制

DiamondHill单张GCD，控制器261728、worker261738均已结束，退出0。包括锁定准备的
墙钟62.111秒，worker主体54.614秒，峰值GPU allocated约11.34 GiB。CPU离线审计
另行执行。一次更新和多次检查不构成正式吞吐或收敛速度基准。

七份坐标的GT对应、独立NumPy lDDT/几何与对齐MSE复算通过，最大差分别2.78e−17、
7.82e−14。56组checkpoint参数复核：初始B为零、更新后均非零；首次更新A保持不变，
符合B=0时该路径导数为零的构造。原参数不变性由更新后、合并前的runtime逐参数检查
证明，离线审计不伪称重新验证了未保存的全部原参数快照。

只读源码检查最初因漏设LAYERNORM_TYPE=torch而触发不兼容的CUDA扩展编译并失败，
未开始模型训练；正式预检沿用已核验的torch LayerNorm环境，一次运行完成。初始化
日志的默认bf16字样先于dtype覆盖；实际手动前向无autocast，参数FP32断言和最终配置
均已保存。不把这项环境检查失败归为模型或backward问题。
