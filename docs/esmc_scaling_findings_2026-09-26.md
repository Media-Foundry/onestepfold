# Scaling-v1 当前可下的结论

原目标不变：ESMC-600M、无MSA、全重原子、一次Pairformer cycle + 一次structure evaluation + K=1，同时追回平均质量和尾部。

八组旧训练均完成。原control2048/cosine128的跨精度QA失败已通过独立的precision-v2补验闭环；原失败保留。补验没有训练或模型推理，只验证5632个唯一保存输出。正式匹配预算分析由HPC3作业654285完成。

## 1. 小集拟合成立，不等于泛化梯度已成立

32-protein达到0.915 Å、32/32<2 Å的容量结论保留。但在相同16384次更新时，当前几何模型的512规模优于128，2048反而下降；不能写成数据越多、泛化稳定变好。

|表示|TRAIN数|dev lDDT|dev TM|CA手性一致率|连续C–N MAE Å|
|---|---:|---:|---:|---:|---:|
|geometry|128|0.2890|0.2814|100.0%|0.5121|
|geometry|512|0.3066|0.3757|100.0%|0.4847|
|geometry|2048|0.2820|0.3293|100.0%|0.8462|
|raw|128|0.3647|0.3731|68.3%|0.3838|
|raw|512|0.3026|0.3704|65.5%|0.5497|
|raw|2048|0.4258|0.5626|62.6%|0.4340|

以上每个目标先平均两个固定noise，再对128开发目标取均值；不是best-of-K。手性和C–N不是完整化学几何验收。当前几何表示保住了手性，但不能把小训练集的链几何达标结论外推到此开发集。

geometry2048−512的mean lDDT差−0.0246，配对target区间[−0.0328,−0.0165]；TM差−0.0464 [−0.0612,−0.0320]。8小时crossing的两项差值同样为负。该负结果限于当前优化预算；不能因此证明2048规模不可训练，或声称已经收敛。

## 2. Raw是重要对照，但目前不能替代最终模型

同为2048 TRAIN、16384更新，raw−geometry的mean lDDT差+0.1437 [0.1325,0.1548]，mean TM差+0.2332 [0.2116,0.2542]；两个worst5%均值差也为正，区间下界>0。只有2/128目标在任一指标下降>0.05。

这支持“当前预算下raw的结构质量明显更好”，不支持“raw已解决最终任务”：它的手性一致率仅62.6%，局部化学仍有明显问题。相同更新也不是严格等FLOPs；此时raw/geometry的优化墙钟分别约5.431/5.832小时。完整报告同时列出原2/4/8小时预算，缺失预算没有用最佳checkpoint补齐。

Raw自身的scaling也并非均值和尾部同步改善。16384更新时，raw2048−raw128平均lDDT差+0.0611 [0.0441,0.0775]，但worst5% lDDT差−0.0382 [−0.0536,−0.0089]。不能只引用较高均值。

## 3. 这不是远同源或新fold泛化验证

沿用既有高gap代价全局比对规则，在相对最大2048 TRAIN、较短序列coverage≥0.8条件下，按aligned-residue identity分层：

|identity层|开发目标数|
|---|---:|
|<30%|0|
|30%–50%|72|
|50%–80%|9|
|≥80%|47|

这是既有划分的事后描述，没有改动数据或打开冻结测试。coverage只针对较短序列，不能当作完整目标链覆盖；0个<30%目标意味着当前开发集无法检验该审计定义下的低同源性能。Raw2048相对geometry2048的优势在30%–50%层也存在，但仍不等于新fold泛化。

## 4. 现在的执行决定

继续且只完成已锁定的endpoint权重1.0实验至8192更新，再做GPU重放、独立CPU验收及最终报告。4096步观察显示lDDT均值与尾部改善，TM尾部尚未追回；不据中间分数改配置或提前选择模型。

保留raw对照；不把当前几何模型写成“已证明泛化更优”，也不因raw分数高而放弃化学门槛。这批证据要求下一次决策同时考虑可优化性、结构质量、尾部和化学几何，不继续以最佳开发均值代替最终目标。此次没有新增方法树或训练。

全部区间为单个训练初始化下的配对target bootstrap（10000次、seed101），不包含训练seed不确定性，未做多重比较校正。中间预算分数来自hash绑定的worker历史，不冒充每个中间checkpoint均已独立坐标重算。
