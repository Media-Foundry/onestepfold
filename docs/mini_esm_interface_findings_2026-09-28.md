## 1. 两次切分的等价性均成立

早期接口包括 ESM 输出、restype 和五类原始参考化学字段。profile 按真实代码与 restype 绑定为同一张量；下游重建参考原子对派生量。没有遗漏发现的可微字段，也没有把 profile 或派生化学特征重复计入独立贡献。

- 切分前后与旧归档的基点 conditioning 逐位一致。
- 所有 15 组 late-interface 差分张量与旧归档逐位一致。
- 本轮完整接口的链式 q 梯度重建误差为零；相对前一轮直接 AD 的 L2 差为 4.19e−10。
- ESM 内部切分：ESM 输出与归档逐位一致，重建的 layer0 输入与实际捕获输入逐位一致，链式 q 梯度重建误差为零。

因此本轮偏差不能归因于这两个切分漏掉了已检查的梯度路径。它不等于认证了所有算子的 backward。

## 2. ESM 输出之前与 Pairformer 段都不是可忽略项

`d−a = (n−a) + (m−n) + (d−m)`。

## 3. 实际下游投影下，ESM Transformer 段偏差远大于 token embedding 段

针对 ESM 路径，固定已保存的输出 VJP μ_E。捕获 layer0 实际输入 T，包含 BOS/EOS、embed_scale 和固定 token-dropout 缩放；计算 ν=grad_T(μ_E·H)。

定义 a_E 为 ESM 路径的 AD，k=ν·ΔT/(2h)，n_E=μ_E·ΔH/(2h)。则

`n_E−a_E = (k−a_E) + (n_E−k)`。

15/15 行都有 |n_E−k|>|k−a_E|。方向 0：

| h | token 输入之前 k−a_E | Transformer＋末端归一化 n_E−k |
|---:|---:|---:|
| .3 | −4.46475e−7 | +5.63483e−5 |
| .1 | −9.25875e−7 | −2.95559e−4 |
| .03 | −1.39588e−6 | −2.27076e−4 |
| .01 | −9.81980e−6 | −1.47564e−3 |
| .003 | −1.72615e−5 | −7.61838e−3 |

这是对上一轮小段参照的重要限定：pW 的无加权向量 FD 相对误差达到 82%，确实证明该小段存在数值差分污染；但它不能解释为“最终坐标导数误差的 82% 来自 pW”。在本轮真实下游投影下，更大的数值／线性化偏差出现在 token 输入到 ESM 输出之间。

这也没有证明 token 输入误差的后续影响可忽略：n_E−k 仍可能混合后续运算的数值误差、有限扰动的强非线性，以及输入误差在非线性网络中的影响。尚不能定罪某个 attention、LayerNorm 或 backward 算子。

R/C 仍单独保留。通过 `(n−a)−(n_E−a_E)` 记录残余，同时注明其中含少量不同 backward 累加路径的影响。方向 0、h=.003 的该项约 −1.17637e−4；未将它偷偷计入 ESM Transformer 偏差。
