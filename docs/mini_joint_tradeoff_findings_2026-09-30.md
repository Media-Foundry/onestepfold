# 联合终点误差分解：目标更低，并不等于接触精度同步提高

这次只读取760c55ea的归档，没有新模型调用、求解或训练。**目标下降主要来自
更贴近raw坐标；尚未消除的全原子误差主要位于涉及侧链、序列间隔≥5的接触。**
同时需修正一个过强的解释：候选Cα-lDDT虽略降，其连续GT距离误差略有改善，
不能称骨架在所有评价下都变坏。原联合筛选失败不改判。

## 1. 范围与计算口径

同一7条开发蛋白、每条两枚C4/S1预测。3CR6的来源失败保留，未增补蛋白。
比较raw、理想局部零角度、拟合后的start、零初始化联合终点和侧链初始化联合
终点五个状态。所有坐标、原子对应、GT和掩码固定，归档及成员哈希全部核验。

AA和CA分别按自己的邻居数计算lDDT：GT距离<15 Å、排除同残基、严格误差阈值
0.5/1/2/4 Å；无向原子对权重为`(1/n_i+1/n_j)/N_valid`。每个互斥分区加回
总指标。先在蛋白内平均两枚噪声，再对7条蛋白等权；没有将14个实例当独立蛋白。

新增的连续距离MAE使用同一GT定义的评估原子对及上述权重，分别比较到GT和raw的
距离误差；它们只是描述量，不是替代验收条件。该GT邻居集合不能用于运行时
目标构造。定义见[分析协议](mini_joint_tradeoff_attribution_v1.md)。

## 2. 联合目标为什么降低

下表为同一rho=100终点目标的加性项，惩罚项已经乘rho。

| 目标项 | 零初始化 | 侧链初始化 | 差值 |
|---|---:|---:|---:|
| raw坐标锚定 | 0.25915750 | 0.21247624 | **−0.04668126** |
| 旋转正则 | 0.00156187 | 0.00146124 | −0.00010064 |
| 扭转正则 | 0.00003088 | 0.00042655 | +0.00039567 |
| 五项连接惩罚合计 | 0.00008102 | 0.00024702 | +0.00016600 |
| 平均排斥 | 0.01152028 | 0.01524944 | **+0.00372915** |
| 最坏16对、位移超限 | 0 | 0 | 0 |
| 总目标 | 0.27235155 | 0.22986048 | **−0.04249107** |

候选12/14份总目标更低，但不是所有几何惩罚更低。普通排斥增加与零严重碰撞
并不矛盾：前者惩罚较轻的重叠，后者只回答固定严重阈值下是否存在原子对。
坐标锚下降说明更接近原预测，不说明更接近实验真值。

坐标/角度正则、连接和预算由保存坐标与参数重算；排斥两项明确复用上一轮已经
独立复算的归档值。本次没有另建化学排除表。此表是目标记账，不是各项的因果实验。

## 3. Cα指标的分歧，应保留而不是挑一个“救回”候选

| Cα评价 | 零初始化终点 | 侧链初始化终点 |
|---|---:|---:|
| 原Cα-lDDT，越大越好 | **0.900562705** | 0.900200802 |
| 到GT的加权距离MAE，越小越好 | 0.487798640 Å | **0.487514467 Å** |
| 到raw的加权距离MAE | 0.098817545 Å | **0.093827281 Å** |

候选相对对照的Cα-lDDT变化−0.000361904，按阈值分解：0.5 Å −0.00009631、
1 Å −0.00008371、2 Å −0.00019130、4 Å +0.00000943。阈值命中率和连续绝对误差
衡量的内容不同，均值方向可以不同。这些数据不证明纯舍入或只有无意义的阈值
效应；但也不支持把小幅lDDT下降笼统解释成全面骨架失真。

5/7蛋白的Cα连续GT距离MAE改善，原Cα-lDDT只在2/7蛋白改善。两组指标都保留，
不改预设筛选、不用事后MAE将上一轮改判成功。

## 4. 局部拟合没有被联合求解整体摧毁

| 阶段 | 全原子lDDT | 到GT距离MAE | 到raw距离MAE |
|---|---:|---:|---:|
| raw | 0.825157133 | 0.744998006 Å | 0 |
| 理想局部零角度 | 0.811601496 | 0.794990242 Å | 0.220097962 Å |
| 排斥侧链拟合后的start | 0.815628947 | 0.780905796 Å | 0.177207707 Å |
| 零初始化联合终点 | 0.816196848 | 0.782167706 Å | 0.226053495 Å |
| 侧链初始化联合终点 | **0.816853576** | **0.779027603 Å** | 0.208653391 Å |

侧链初始化后的联合求解，仍使AA提高0.00122463、GT距离MAE减少0.00187819 Å。
最终相对零初始化的优势变小，也包括对照自己追回了局部误差；不能将其全部解释
为新初始化的收益被破坏。

但联合求解的变化并不均匀。由start到侧链终点：

| 序列间隔 | 对AA变化的加性贡献 | GT距离MAE变化的加性贡献 |
|---|---:|---:|
| 1 | +0.00057129 | −0.00239360 Å |
| 2–4 | +0.00063739 | −0.00374405 Å |
| ≥5 | +0.00001594 | **+0.00425946 Å** |

近序列邻居改善，远隔类阈值总分几乎不变、连续误差有所增加；这只是所测输出间
的描述，不能单凭分区就指定连接惩罚是原因。所有这些原子对的GT空间距离仍小于
15 Å，不能称为无限空间长程误差。

## 5. 剩余主要差距在哪里

侧链初始化终点相对raw的AA差距仍为−0.008303557：

| 配对类别 | 支持权重 | 对总差值的贡献 |
|---|---:|---:|
| 骨架—骨架 | 27.1% | −0.00023852 |
| 骨架—其他 | 49.7% | −0.00448866 |
| 其他—其他 | 23.3% | −0.00357637 |

骨架定义为N/CA/C/O，其他含侧链和OXT。按序列间隔：1为+0.00045950，2–4为
−0.00047111，≥5为−0.00829194。≥5本身占79.8%的支持权重，不能把其净贡献
换算成“99.9%的机制由长程作用造成”。

相对零初始化，AA到raw的距离误差在7/7蛋白都减少，但GT误差并不统一改善：

| 蛋白 | ΔAA-lDDT | ΔGT距离MAE | Δraw距离MAE |
|---|---:|---:|---:|
| 2FC3 | −0.00219429 | **+0.00589066 Å** | −0.02035833 Å |
| 4B9P | −0.00125447 | **+0.00456244 Å** | −0.00966827 Å |
| 5GU9 | +0.00393755 | −0.01327246 Å | −0.02081675 Å |
| 3D8L | +0.00336304 | −0.01460451 Å | −0.03644148 Å |

因此不能承诺“只要更保持raw距离，就一定恢复GT精度”。这四例只是事前指定的
正负例对照，全部7蛋白及逐噪声数据都在产物中，没有按GT选运行时初始化。

## 6. 核验与下一项方法决策

独立路径用稠密有向距离矩阵和逐中心归一化复算：140组状态/指标、2,100条分区、
1,440条蛋白/总体汇总全部通过。最大分区误差6.66e−16，汇总误差0，目标求和误差
6.82e−14。沿用旧化学元数据；这不是新的化学验证，也不是新的独立蛋白测试。

**本轮不继续追查小幅Cα分数下降，也不重开初始化和精度实验。** 后续更有针对性
的一项干预是：在原整参考零初始化联合求解基线上，单独检验显式残基间距离保持
项，观察能否在同样几何约束下保留更多原折叠接触。其原子对与目标必须仅由raw及
原生拓扑决定，不能用本次GT邻居集合；在运行前冻结单一公式、权重和预算，不做
网格搜索，不同时使用失败的侧链初始化来混合改动。

这是待验证的假设，不是已证实的修复。2FC3/4B9P已经给出反例，说明更贴raw并不
保证更准确。若单项干预仍无联合收益，就应停止raw保持目标的小幅修补，转而评估
具有独立实验结构监督的输出映射；不为让旧筛选通过而反复增加预算。

现阶段仍无可部署、贯穿求解器可反传的一步输出，旧独立32结果和几何标准不变。
