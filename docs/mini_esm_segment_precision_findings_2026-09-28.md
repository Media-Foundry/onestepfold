# ESM 局部精度诊断：所测末段主要是 FP32 前向差分污染

2026-09-28。本轮第一次用冻结实际端点和精度干预区分了误差类型：在 control 原失败点的 ESM 第 25–36 层，FP32/FP64 局部 AD 响应接近，高精度 secant 与高精度 AD 也接近，原先的大偏差主要来自 FP32 前向 secant。这个结论限于所选层段、固定投影与所测端点，不是完整序列梯度认证。

## 运行时实现和 FP64 参照确实经过检查

DiamondHill 实际环境：fair-esm 2.0.0，PyTorch 2.12.0a0+git78258b9，HIP 7.14.60850。实际导入 attention、rotary、modules 文件路径和 SHA256 均已归档。GitNexus 索引更新到 af4e05d7；本轮数值结论来自运行时源码与计算记录。

- 原生 attention 的 `utils_softmax` 确实强制 FP32。只有独立参考上下文允许 FP64 logits 使用 FP64 softmax；退出及异常退出均验证恢复原函数。
- 原生 RoPE 缓存刷新不检查 dtype。本轮保存原生实际 cosine/sine 表，精确升精度使用，没有重新生成位置常量。
- 实际 LayerNorm 是 `torch.nn.modules.normalization.LayerNorm`，epsilon=1e−5；没有 Apex/fused 替换，维度、参数、epsilon 不变。
- 参考权重来自同一运行时 FP32 权重数值的精确升精度版本。复制过程逐参数验证数值相同。
- 参考 FP64 前向追踪的 865 个浮点算子输出全为 FP64，12 次 attention softmax 的输入与输出均为 FP64，未发现显式降精度。此检查观察算子张量 dtype，不声称审计了每条 GPU 内部指令。
- 参考 FP32 与原生 FP32 的基点、所有正负端点输出和 AD 投影完全一致。因此在这些实测输入上，参考实现变更没有引入额外 FP32 差异。

生产模型保持原样；不是 `.double()` 后未经核查就称为 FP64 参照。

## 按预先规则选中第 25–36 层

36 层分为前三分之一、中三分之一、后三分之一，再单列末端 LayerNorm。保存五个边界的真实 u0/u+/u−，没有从 delta 伪造对称端点。原 ESM 基点及全部输出差分精确重放。

选择规则预先锁定为：原方向 0、h=.003，四段中绝对偏差最大的段。该行有符号偏差为：

| 层段 | 导数尺度偏差 |
|---|---:|
| 第 1–12 层 | −8.47401e−4 |
| 第 13–24 层 | +3.55216e−3 |
| 第 25–36 层 | −1.03261e−2 |
| 末端 LayerNorm | +2.98372e−6 |

因此只对第 25–36 层追加精度对照。各段有抵消，不能解释成错误贡献百分比。选中段的原生重放逐位一致，局部 VJP 与完整 ESM 边界 VJP 的重建误差为零。

## 三项分解给出了明确的局部解释

固定同一组实际 u0/u+/u−、同一 μ，令 v_h=(u+−u−)/(2h)。这里 A 是对这个**中间 secant 方向**的局部 AD 投影，不是原始 logits 方向 AD，所以 A 随 h 改变并不矛盾。

`S32−A32 = (S32−S64) + (S64−A64) + (A64−A32)`。

原方向 0、h=.003：

| 项 | 数值 |
|---|---:|
| 原生 FP32 secant S32 | −7.628179e−3 |
| 原生 FP32 AD A32 | +2.697947e−3 |
| 参考 FP64 secant S64 | +2.697988e−3 |
| 参考 FP64 AD A64 | +2.697965e−3 |
| 原生差异 S32−A32 | −1.0326126e−2 |
| 前向 secant 精度差 S32−S64 | −1.0326167e−2 |
| 高精度有限端点余项 S64−A64 | +2.27919e−8 |
| 局部 AD 精度差 A64−A32 | +1.80940e−8 |

全部 15 行均是前向 secant 精度差的绝对值大于其余两项绝对值之和。这是同一目标的方向／步长诊断计数，不是总体发生率。

| 量 | 15 行绝对值范围 |
|---|---:|
| 原生差异 | 8.33e−6 ～ 1.033e−2 |
| 高精度有限端点余项 | 1.79e−10 ～ 2.28e−8 |
| 局部 AD 精度差 | 9.35e−12 ～ 5.74e−8 |

FP32/FP64 AD 投影最大相对差约 1.05e−4（0.0105%）；FP64 secant/AD 最大相对差约 3.44e−4（0.0344%）。没有改变原门槛、替换旧的端到端 gate 或以零信号通过冒充认证。

分子尺度也保留了：方向 0 的原生 2h(S32−A32) 在 h=.3/.03/.003 时分别约 −1.45e−5、+1.18e−5、−6.20e−5。冻结端点后，高精度干预将对应余项显著压低，因而证据比单纯观察“分子不随 h 下降”更强。

## 非对称端点与真正 JVP 也已检查

方向 0 的端点中点偏移范数约 .0105–.0111，端点半径约 .0122–.0132。这些是未归一化的中间张量范数，不是坐标 RMSD。实际非对称端点被完整保留；高精度余项没有被命名为纯曲率，仍包含中点偏移及参考运算的残余误差。

局部段移除了 checkpoint 包装，保留相同数学模块；真正的 `torch.func.jvp` 在参考 FP32/FP64 全部成功：

- FP64 JVP/VJP 最大绝对差 4.38e−17，最大相对差 1.50e−13。
- FP32 JVP/VJP 最大绝对差 8.11e−9，最大相对差 5.31e−5。
- FP32 JVP 的方向需转为 FP32；其量化误差已记录，VJP 比较使用同一量化方向。主三项分解仍用精确升精度的实际端点 secant。

JVP/VJP 相符不是通用正确性证明，但与 FP64 secant/AD、原生 FP32 AD 和参考 FP32 精确重放一起，支持该局部段的导数在所测方向上数值一致。没有使用 backward-of-backward 冒充独立前向模式。

## 应更新的判断与保留的问题

现在应将这个局部段的旧 FD 失败解释为：**当前 FP32 前向差分在该扰动尺度上不足以可靠验证 backward**。所测余项不支持把主要差异归为强有限扰动非线性，也不支持据此判定 backward 实现错误。不能因为旧记录写着 fail，就继续坚持“梯度一定坏了”。

但仍不能把这个结论推广成完整 ESM 或完整序列梯度已通过：其他 ESM 层段、输入编码／Pairformer，尤其原方向 2、h=.003 的中段偏差尚未得到同样的精度干预。hard 几何失败也独立保留，部署仍不通过。

下一项应复用本轮方法到 Pairformer 已有失败点，保持实际端点、位置常量与原生 FP32 对照，再决定哪里需要数值验证路径或生产实现调整。没有依据启动 LoRA、改变训练配方或把整个部署模型改成 FP64。
