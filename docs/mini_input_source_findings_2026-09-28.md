# Hard 邻域与输入源拆分：2026-09-28

**本轮最重要的修正：在所测大幅全序列软化下，整体失真主要随 ESM 输入路径出现；8BZN 的特定近重合原子对则涉及 E/R/C 与位置范围的组合效应。不能把主要原因单独归给 reference chemistry。**

全部实验为 forward-only；模型、diffusion、loss 和验收门槛保持不变。仅使用已有开发目标 8BZN 与 control（9XVW），没有动冻结测试集。没有训练、LoRA、平滑距离或序列优化。

## 1. 对照是否可信

固定原生原子图、顺序、身份绑定 noise211、C4/S1/K1、FP32、打包方式；关闭 dropout/随机增强。

- E：按实际概率重新经过原生 ESM2-3B；one-hot 路径与官方原生 ESM 输出逐位一致。
- R：仅改变当前代码中的 `restype/profile`；不改 `deletion_mean` 或 MSA。
- C：沿用当前五项 reference 插值，不归一化缺失原子、不对齐构象、不修改原子身份。
- 每个 α 重算 reference pair 特征、完整 Pairformer conditioning 及 diffusion cache。两个 atom encoder 的真实 cache 调用都核对了当前五项 reference 字段及 `d_lm/v_lm`。
- 所有 α=0 输出在同一目标的各组间逐位一致；未干预字段的差异为零。
- 138 份保存坐标完成独立 CPU FP64 几何复算，最大统计差异约 1.47e-7。这里的 FP64 仅用于验收，不是模型 forward。

最初的源码预检因本地多出的未调用边界辅助函数与冻结副本文件哈希不同而停止，未执行 forward。已保留失败记录，核对差异并修正源码清单；ESM 包未重复抽取，父子协议哈希显式绑定。

## 2. Hard 邻域没有观察到不收敛的跳变

概率路径严格采用非原生总质量 α，而不是改变 logits 饱和程度。完整 ERC 的 Cα 对齐偏移如下，参照是原生 **hard 模型预测，不是实验 GT**：

| α | 8BZN Cα 偏移 Å | control Cα 偏移 Å |
|---:|---:|---:|
| 0 | 0 | 0 |
| 0.0001 | 0.0030 | 0.0129 |
| 0.001 | 0.0301 | 0.1566 |
| 0.01 | 0.3553 | 1.1751 |
| 0.2581587 | 13.7073 | 2.1983 |

这些采样点支持“靠近 hard 时输出趋近 hard”的局部图景；不是全局连续性证明，也没有通过完整序列 FD。control 对小概率变化更敏感。原生 hard 起点本身已有碰撞，故“变化小”不能等同于“化学有效”或已得到设计安全半径。

## 3. 大幅失真与特定原子对失效必须分开

在 α=19/(exp(4)+19)≈0.2581587，即每个位点约25.8%非原生概率质量时：

| 8BZN 输入源 | Cα 偏移 Å | <1 Å 非共价对数 | HIS42-CE1 / THR43-OG1 距离 Å |
|---|---:|---:|---:|
| Hard | 0 | 8 | 6.2666 |
| E | 12.8320 | 236 | 7.0708 |
| R | 0.8459 | 13 | 6.4396 |
| C | 0.4754 | 11 | 4.9261 |
| ER | 13.8261 | 225 | 3.8234 |
| EC | 12.9692 | 205 | 7.1422 |
| RC | 1.4886 | 22 | 5.1334 |
| ERC | 13.7073 | 236 | 0.0318 |

E-only 已足以产生大幅整体偏移与大量碰撞；R/C 单独不足以解释这一量级。与此同时，该特定近重合原子对仅在完整 ERC 端点复现；不能把它视为某单个字段的独立效应。

control 的 E-only/R-only/C-only Cα 偏移分别为2.2580/0.4257/0.7409 Å；组合并非单调变差，EC 为2.6879 Å，ERC 为2.1983 Å。这里检验的是当前 soft ESM 连续扩展在大幅输入扰动下的行为，不是 ESM2 与 ESMC 的质量比较，也不意味着原生 ESM2 有 bug。

显式概率路径与原 FP32 softmax 初始化最多相差5.96e-8。单独重放旧 softmax 得到原子对0.0314 Å、235对碰撞；显式路径为0.0318 Å、236对。两者都复现严重失真；整数碰撞数的一个边界差异不改变结论。

## 4. 仅软化局部位置不能复现整体失效

保持同一 α，分别仅软化42/43两个位置，或其余123个位置：

| α≈0.258，8BZN ERC | Cα 偏移 Å | 严重碰撞数 | 指定原子对距离 Å |
|---|---:|---:|---:|
| 仅42/43 | 0.1964 | 11 | 5.1529 |
| 其余位置 | 13.5999 | 218 | 3.6295 |
| 全部位置 | 13.7073 | 236 | 0.0318 |

只软化其余位置的 E-only 也有约12.80 Å Cα偏移。该具体失败并非仅由两个原子所在残基的局部参考输入决定；整体 conditioning 与局部输入变化共同影响结果。两种位置干预改变的位点数不同，不能据此比较“每个位点的重要性”或断言远处位点单位效应更强。

## 5. Reference chemistry 的实现问题仍然存在

源码与导出 bank 均确认：缺失原子槽以零值参与平均。THR43-OG1 仅在20种候选中的1种存在，HIS42-CE1 在3种存在。大 α 下 reference mask 最小值约0.74184，两目标的参考同残基键长相对 hard 的中位比值都约0.752。

不同候选参考构象也并非处于同一个直接可平均的坐标表示：例如THR43候选骨架相对原生的未对齐 RMSD 中位值约2.55 Å，刚体对齐后约0.049 Å；其他残基的对齐后差异未必同样小。这是表示一致性问题的证据，但 C-only 结果表明，它不能单独解释本轮主要全局失真。此轮没有用重新对齐或存在概率归一化修补它。

## 6. 前轮 FD 的坐标尺度解释

已保存的近重合原子对，基准距离0.031421 Å：

| h | 最大相对向量位移 Å | ρ(h) |
|---:|---:|---:|
| 0.003 | 0.117025 | 3.7244 |
| 0.001 | 0.038897 | 1.2379 |

所以这些 h 对该原子对并非相对小扰动。此前74%–90%是选定方向的 **clash 非线性余项的有符号贡献比例**，不是梯度错误百分比；没有替换原 FD 标准。

## 结论与下一步边界

当前证据支持：固定图下存在值得继续检查的 hard 邻域，但把所有位置直接软化到原生概率0.742已经远离它。主要整体失真不能归给 diffusion 调用次数或单独 reference 路径，特定原子近重合也需要考虑输入源与位置交互。

下一步建议在 hard 与很小 α 下重新做原随机方向 FD，并保留全原子几何检查，确认正常输入邻域是否仍有导数失败。reference 表示重定义应单列受控对照；不应先平滑 loss 或训练 LoRA 来补偿当前输入失真。这个下一步尚未启动，部署判定仍不通过。
