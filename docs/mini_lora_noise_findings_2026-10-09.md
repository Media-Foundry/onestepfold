# Mini末轮LoRA噪声覆盖对照：终态分析

2026-10-09。执行`lora_noise_v1_20261008`，按[锁定协议](mini_lora_noise_v1.md)完成，**收口、不晋升**。双噪声监督在两枚种子上都减少了保留集新增几何失败，但没有建立更可靠的候选选择，也未全面修复结构质量。它验证了训练噪声覆盖会影响部分退化，不支持“迁移失败主要因为少训练了一枚噪声”的统一解释。

## 实验与完整性

4条新训练：single/dual × 272001/272003。固定Mini、WT3缓存、原生候选末轮、冻结S1、rank16/655360参数LoRA；数据、损失权重、AdamW、clip和AA顺序不变。每条8208次更新，globalbatch2，15条TRAIN蛋白/27个位点/513个mutant，每候选32次曝光。single只使用230201；dual每候选230201和230211各16次。两臂每个种子使用同一个step0及优化器状态，全部从零DDP训练，未追加或选择旧checkpoint。

候选自身归档s_inputs、query-MSA特征和化学仍合法进入原生末轮；没有oracle target最终s/z。没有ESM/MSA准备、新C4、RCSB采集、解冻或阈值调整。噪声只决定S1噪声及对应teacher坐标，不是conditioning网络输入。

全部训练、0/4104/8208评测及最后回放完成。控制器14309.58秒（约3小时58分），包含排队、训练、评测和审计，不是纯训练基准。4个终点DDP副本哈希一致，每rank8208次候选recycle及S1，无input_embedder/C4调用；合计32832次正式优化更新、65664次训练候选解码。8次预检更新单独丢弃。

每条运行的3个checkpoint固定案例回放逐位一致；候选顺序检查及48个位点关闭LoRA恢复检查全部通过。step0全量坐标是原审计结果的哈希验证复用，不声称本轮重新生成。

回收24份远端JSON并逐份SHA256校验。另提取1152条site-arm记录及原压缩评分文件哈希；独立复算3456个Spearman和1152个跨噪声regret，与归档一致。实际曝光表全部核实为32或16+16。审计脚本只读结果、不修改模型。

## 几何改善主要来自哪里

| 统计，相对无适配 | 单噪声①→双噪声① | 单噪声②→双噪声② |
|---|---:|---:|
| 230201新增失败 | 11→10 | 5→10 |
| 230211新增失败 | 68→29 | 62→30 |
| 2FKZ新增失败（两噪声） | 36→1 | 23→3 |
| 2EBE新增失败（两噪声） | 25→25 | 18→26 |
| 全保留集严重碰撞对总数 | 2502→2358 | 2110→2170 |
| 全保留集错误手性中心实例总数 | 401→371 | 435→372 |

新增失败净减少40/27份，其中2FKZ减少35/20份，占87.5%/74.1%。这是计数贡献，不是因果解释率，也不是35/20个独立错误机制。此前定位2FKZ的失败集中在155:CG–155:OXT，本批按归档原子结构几何规则确认该蛋白严重碰撞总数由38/24降到2/4；本次没有重新枚举双噪声残余的具体原子对，不能断言其全部仍是同一对。

改善并未覆盖2EBE：第二枚种子该蛋白通过数11→0，严重碰撞对308→536，错误手性中心70→84。全保留集第二枚严重碰撞对也增加，尽管通过份数上升。

因此双噪声对已测试的第二枚采样状态更稳，是有重复证据的局部收益；但不是完整化学质量改善。230211在dual中已用于TRAIN，**不是未见噪声泛化测试**。保留蛋白仍未参与参数更新，但仅两枚既定噪声和反复使用的开发蛋白不能提供独立确认。

## 选择风险的变化可追到具体位点

两枚dual终点在全部18个位点上选择完全相同，因而平均regret恰好相等；不是四舍五入巧合，也不代表选择正确。

种子1有5个相对single改变的选择，种子2有6个。共同变化包括：

|---|---|---:|
| 1X8D I25 | C→P | +0.00846 |
| 1YSB V5 | M→E | +0.02799 |
| 4PQL E89 | I→L | +0.02734 |
| 3SXZ R101 | T→F | -0.00149 |

4PT4 L10在两种子single分别选P/M，dual均选Q，因此一枚改善、一枚恶化。种子2最重要的额外变化是2EBE E47：Y→D，regret从0.01223升至0.39214，增加0.37991，约占该种子18位点regret净增加的83.0%。各蛋白本面板均两个位点，位点平均与蛋白平均的贡献换算一致。这不是模型机制的解释率。

两枚dual还保留了此前6ZRW P80的高代价选择。几何通过大幅增加，并没有自动改善高风险候选选择；同样，某个训练目标让两种子选择更一致，也不等于风险更低。

噪声覆盖改变了风险分布，训练regret两枚都改善，但通过数两枚都下降，手性总数一升一降。不能说它只是统一加强了所有训练指标。

2ED6的76份输出在所有这些路径中仍全部失败。single→dual严重碰撞对4579→4346、6109→3657；手性中心504→570、496→487。第一枚进一步说明总碰撞数下降与手性改善不是同一件事。teacher本身存在几何问题，现有结果未把坐标拟合和化学损失的优化冲突单独分离，不能直接指定权重或某个模块为根因。

三个同蛋白新位点的Spearman两枚均下降：0.67310→0.64094、0.69591→0.63216；regret均维持0.12743，几何通过60→58/57。不能用保留蛋白平均几何改善替代同蛋白新位点的结果。

4104中点只作轨迹记录：dual保留几何通过411/422→终点426/427，single为378/399→370/381。终点选择规则未更改，不事后挑checkpoint。

## 成本与执行边界

每臂训练的候选解码次数相同，dual没有把每步解码翻倍。四条单独训练wall time为6889/7383/5485/6149秒，受并发调度和输入开销影响，不把这四项差异解释为噪声方法固有速度差。

最终隔离回放的1W53、19候选、每候选一次S1，四条路径的原生C4耗时中位数约6.20–6.36秒，适配续算约2.26–2.32秒，约2.74–2.75倍缓存内折叠加速。一次WT成本在续算账本内。ESM/MSA准备、模型冷加载、磁盘和评分不包含；这不是质量已经通过的部署加速。

## 路线判断

这项对照完成了其目的：噪声覆盖对部分几何风险有可复现影响，却没有使候选选择和完整响应达到可靠迁移。保留双噪声作为有价值的研究对照，不能晋升成合格C4替代，也不能把本批失败再归结为“只差更多噪声”。

本轮正式收口，不自动追加种子、训练步数、噪声数量、rank或损失混合。继续研究前，需区分是否要优化teacher响应保真、原生几何修复或筛选风险；当前结果不足以保证同一项小改动能同时解决三者。后续确认必须使用未参与选择的蛋白与未训练噪声。本批没有启动新训练。
