# 从随机初始化训练一步折叠模型：分阶段计划

状态：用户已要求从过拟合测试开始；本轮只实施第一阶段的 TRAIN4 对照。
长期目标为冻结 ESMC-600M、无 MSA、全重原子单体、一次残基关系模块计算、一次结构网络计算、一个输出样本。折叠核心不加载任何已有折叠权重，不使用教师坐标训练。

这里的“从零”指折叠核心。ESMC 仍提供预训练序列表征。旧 scratch 本身已使用随机 ESMC 投影，因此重新初始化不构成架构创新。首先建立监督与训练效率的可靠基线，再决定新架构与一步生成目标。

## 最终目标与指标

- 同口径全原子 lDDT 宏平均以 0.89–0.90 为研究目标；逐蛋白 P1 ≥0.70。二者均是待验证的项目目标，不是跨数据集通用基线。
- 对每个蛋白，按有效观测重原子分别计算邻域 lDDT，再对有效原子平均；随后对蛋白等权平均。半径 15 Å，严格小于阈值 0.5/1/2/4 Å，排除同残基原子对；不填补缺失 GT，不作侧链对称重命名。保持当前 `scaling_metrics.lddt_observed` 口径，并单列未来对称感知评估。
- 分开报告均值、中位数、P1、最低 `ceil(0.01N)` 个蛋白的均值、低于 0.70 的比例。P1 与最低 1% 均值不是同一指标。
- 两个固定推理噪声的逐蛋白平均用于历史对照；同时分别报告每个噪声的尾部与失败率。部署 K=1，不取 best-of-K，不把推理噪声当成独立训练种子。
- 同时检查 Cα-lDDT、TM-score、RMSD、局部键长/手性、后续完整碰撞和立体化学、置信度校准及实测延迟。ESMC 提取计入端到端开销。

## 已有证据和避免重复的工作

旧 Capacity-C 已证明 TRAIN32 可拟合：raw 在每条 650 次曝光时通过，几何适配版本在 400 次通过；100 次未通过不能解释成没有容量。旧 scratch 在较大训练集的分数仍低，说明小集记忆能力与大集学习效率需要分别验证。

现有预训练路线只作参照。已运行的固定续训保持源代码、优化器、数据与终点不变；新的 scratch 工作使用独立目录。用户当前选择更新此前“先做预训练能力保持，再考虑 scratch”的优先顺序。首轮不启动教师保持、非线性桥接、MLC 或深度网格。

## 阶段 1：TRAIN4，检验新监督是否可学且有帮助

复用旧 TRAIN32 中长度排序索引 `[0,7,15,31]`，包含最短与最长；不根据预测误差选样，不读取 DEV/test。具体序列、实验标签、掩码、输入及化学库存全部绑定原已验收数据哈希。

模型沿用已验收拓扑作为 v0：16 个 Pairformer block、8 个结构 transformer block，随机初始化 ESMC1152→449 投影和全部折叠核心，seed=101。构造时禁止加载折叠 checkpoint，并检查原随机初始化哈希。只使用冻结 ESMC 的 final-layer 输入；c1/s1/K1，结构输出为 raw XYZ。confidence/distogram 冻结且不执行；本阶段不声称已实现新的结构架构。

两臂从相同随机状态开始：

| 臂 | 优化目标 | 本轮变量 |
| --- | --- | --- |
| baseline | A + 0.1F + R + 10D | 匹配的原训练监督 |
| smooth_lddt | A + 0.1F + R + 10D + 10L_smooth | 仅增加可微全原子 lDDT 项 |

A 为观测原子刚体对齐后的坐标 MSE，F 为局部 frame 误差，R 为同残基 frame 误差，D 为原四类键距误差。L_smooth 与真 lDDT 使用相同 GT 邻域和逐原子归一化，以 `sigmoid((threshold - abs(distance_error))/0.1 Å)` 平滑阈值，损失为 1 减平滑分数。完美坐标的平滑损失略大于零，真实 lDDT 仍独立计算。固定权重 10 是一个预声明工程候选，不宣称最优，不自动扫权重。

两臂一致：AdamW lr=1e-4、weight_decay=1e-4、clip=10、batch=1、dropout=0、BF16 trunk/FP32 structure、TF32 off、一次结构调用。每个 epoch 每蛋白一次更新；顺序与训练噪声继承旧确定性规则，评估噪声 12345/54321 不参与训练。每 50 次曝光评估；上限 1000 次曝光/蛋白（4000 更新）或 2 小时优化时间，每作业硬上限 3 小时，单 H100、HPC3 acd_u。

运行前验证 loss 掩码、刚体不变性、独立数值公式、有限差分梯度、空邻域；GPU 预检检查初始坐标重现、最长输入反传、真实一次 trunk/structure 调用、输入冻结。正式运行每个评估点保存逐蛋白/噪声质量、原损失各项和新增项、梯度范数、耗时；保存 best/last checkpoint 和优化器，结束后精确重放 best 并独立 CPU 验收 initial/best/last 坐标。

通过门槛必须在两个评估噪声下同时满足：

- 每条蛋白全原子 lDDT ≥0.90，且每条观测原子 RMSD <1 Å。
- pooled Cα 距离 RMSE ≤1 Å。
- N–CA/CA–C/C–O RMSE ≤0.15 Å；C–N ≤0.30 Å；手性一致率 ≥95%。

最优 checkpoint 使用最大归一化门槛违反程度的最小值，平局取更早者。通过后停止；否则达到预算或数值失败停止。主比较包括共同曝光点曲线、首次过门曝光、优化更新数、实际 GPU 时间；提前停止之后不外推。数值失败属于实现/优化失败，时间耗尽属于预算截断，均不能直接否定架构容量。

这个匹配 baseline 是新 lDDT 门槛和新运行协议的对照；不重跑整个旧 1/4/32 方法矩阵。四条拟合不用于声称泛化或 P1 达标。若新增项饱和、没有收益或损害几何，保留负结果，不自动追加 loss 网格。

## 阶段 2：TRAIN32，再到 TRAIN128/512

先阅读 TRAIN4 的独立验收结果，再确定进入 TRAIN32 的一个候选。复用旧 TRAIN32 及几何门槛，增加逐目标 lDDT 报告；新损失如无有效信号，不将其默认推广。旧结果用于历史参照；需要因果归因时才增加匹配对照。

TRAIN32 的计划上限沿用每蛋白 1000 次曝光，具体 GPU 时间由第一阶段实测速率预先锁定。通过只证明小集可学习。然后分别锁定 TRAIN128 与 TRAIN512 的训练上限和曲线检查点，评估完整训练集或预声明覆盖各层次的训练样本，不再只看 TRAIN32 探针。若大集训练分数仍低，优先研究监督/优化效率，不能直接归因于泛化。

## 阶段 3：建立独立泛化评估并扩大训练

在观察新评估结果前锁定数据版本、家族/同源簇划分、长度/结构质量分层、训练预算、模型选择规则。已有 DEV128 仅作历史开发集；本轮不打开冻结 test，也不将其重新分配为开发集。独立开发目标需明确从未用于拟合、调参或候选选择。

训练规模按已验收可用数据从 2048 到 8192，再扩至经过审计的更大集合。报告样本曝光、残基/原子 token、GPU 时间与学习曲线；固定短预算的落后不能解释为训练至充分收敛后的能力上限。避免近同源重复主导采样。结构上下文不足、缺失观测、实验构建体与真实单体适用范围必须保留在审计中。

独立评估争取覆盖至少 1000–2000 条适用目标，并按家族分层；这仍只有约 10–20 个 1% 尾部目标，需置信区间和家族相关性说明。最终一次冻结测试须在模型/协议选定后执行。

## 阶段 4：按失败模式选择一种模型改进

训练集也差：先查优化与监督，再考虑一次结构计算内增加深度（例如结构 transformer 8→12），独立对照并记录实际延迟；不得仅靠调用次数相同声称等算力。

训练集高、独立开发集尾部差：优先检查家族覆盖、采样、长度与条件信息充分性；只在 TRAIN 侧定义困难样本策略，不针对 DEV 坏例过采样。

一步输出明显受限：把 MeanFlow 或直接一致性训练作为单独候选，在相同数据/推理约束下比较。先推导蛋白坐标参数化、噪声路径、刚体处理、掩码及 JVP/梯度，再做小集门槛。普通多噪声 flow matching 训练不能直接等同于高质量一步生成。

ESMC 接口/信息受限：再单独检验原生非线性输入映射或预声明多层表征；不与新 loss、深度、采样同时改变。新架构可借鉴已有模块，但不加载已有折叠权重。

## 阶段 5：重复、置信度和最终验收

候选收敛后至少做 3 个独立训练种子，保留每个目标与每次单样本推理结果。结构预测稳定后训练并校准置信度；不使用置信度筛选来隐藏 K1 失败。锁定最终训练数据与协议，再执行独立测试。

完成要求包含同口径均值目标、低尾目标、化学有效性以及实际端到端速度。均值提升但尾部退化不算完成；达到原生约 0.82 仅是中间参照。每阶段产物包括协议、不可变源码清单、数据/初始化哈希、曲线、逐目标结果、独立验收和下一阶段决定。
