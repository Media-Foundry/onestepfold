# Mini末轮LoRA：几何退化定位（2026-10-08）

本次只分析既有坐标与评分文件，不训练、不执行模型推理、不修改阈值。主结果使用预定8208终点，4104仅用于轨迹描述。种子顺序为272001、272003。九条保留蛋白仍是开发数据。原始两份scores.json.gz的本地与远端SHA256一致；数据出处和导出文件哈希见[manifest](../reports/mini_lora_geometry_2026-10-08/manifest.json)。

## 判定口径

沿用原评分器：排除键图距离不超过3的原子对，剩余距离<1 Å为严重碰撞；检查非Gly的CA及Ile/Thr的CB参考定向手性体积，体积乘参考体积<=0为错误。联合通过要求两项均无错误。这不是完整化学质量认证，不包含完整键长、键角等验收。

逐输出检查归一化手性体积<=0的数量与归档错误数完全一致。对终点所有“无适配通过→LoRA失败”且含碰撞的输出，使用原生inventory及原排除规则重新枚举原子对，数量全部与归档一致。分析代码不改原评分实现。

## 2. 两种性质不同的集中错误

| 蛋白 | 新增失败：种子1/2 | 主要定位 |
|---|---:|---|
| 2FKZ | 36/23 | 全部是第155残基CG–OXT同一原子对<1 Å |
| 2EBE | 25/18 | 第13–16残基附近多对原子碰撞，伴随CA手性翻转 |
| 1YSB | 10/10 | 多种碰撞以及第2残基CA翻转 |
| 6AHP | 2/14 | 第1残基CA翻转 |
| 1X8D | 3/0 | 第2残基CB翻转 |
| 4PQL | 3/2 | 第130残基CG与第131残基CD碰撞 |
| 4PT4、3SXZ、6ZRW | 0/0 | 零新增不代表绝对质量合格；6ZRW原通过为0 |

2FKZ训练外位点为E44/Q137，新增碰撞在155而非突变原子。相同原子对在无适配输出的距离范围分别1.0385–1.2081、1.0385–1.1865 Å，LoRA后0.8041–0.9940、0.8357–0.9965 Å。因此它是重复的末端局部缺陷，不能当成59个独立机制。保留严格1 Å阈值，不因集中于末端而删除。

2EBE新增失败输出中的严重碰撞对共294/177个；最常出现的对包括13:CG–14:N、13:NE2–15:N。对应无适配距离中位数3.0726/2.8523 Å，LoRA后0.7464/0.7341 Å，最短0.1909/0.2213 Å。这里不是都在阈值附近。两个突变位点为A30/E47，主要碰撞区也不在突变位置。

保留集新增失败中，错误手性中心实例为36/32个，全部不在突变残基。种子1主要为2EBE CA16（21次）；种子2为6AHP CA1（14次）及2EBE CA16（10次）。

6AHP确有边界退化：翻转前参考定向体积比范围约0.00058–0.01231。2EBE不能一概如此解释：翻转中心的无适配体积比最高0.7671/0.8023，LoRA后最低-0.2299/-0.2104。体积比是相对于候选reference chemistry，不是相对于teacher坐标。

## 3. 训练通过数改善并非全面几何改善

训练通过数427→516/516，但所检错误手性中心实例总数853→1099/1146。严重碰撞对总数10360→8439/9925。以上是跨所有输出求和，同一中心或原子对可重复出现，不是独立样本数。

109/103份修复中，2DP9、5MH3、2ARC分别贡献25/26、41/36、32/31，合计98/93份（约90%）。这是真实但集中的修复。

同时2ED6全部76份输出在无适配和适配后都失败，因此通过数不显示它的进一步退化：

| 2ED6，76输出求和 | 无适配 | LoRA种子1 | LoRA种子2 | Exact C4 |
|---|---:|---:|---:|---:|
| 严重碰撞对 | 2907 | 4579 | 6109 | 5070 |
| 错误手性中心实例 | 152 | 504 | 496 | 393 |
| 联合通过 | 0 | 0 | 0 | 0 |

Exact自身较差，说明贴合teacher坐标与改善化学可能存在张力；但学生某些错误还超过Exact，不能把全部恶化归因于忠实模仿teacher。当前未做梯度冲突或损失项因果干预，不指定哪一项损失导致问题。

## 4. 4104时已存在退化，继续训练扩大了范围

保留集新增失败从63/49增到79/67；终点新增失败中有58/41份在4104时也已失败。两个时间点不能证明过拟合机制，更不能事后选择4104代替锁定终点。

## 5. Regret的种子差异由极少数选择改变驱动

18个保留位点中，种子1只改变3个位点的旧噪声选择，种子2改变5个；所有其余位点保持原选择。

两枚种子都将6ZRW P80从C改选V，单个位点新噪声regret增加0.270514；共同的两项小改善为1YSB V5（E→M，-0.027993）和1X8D I25（P→C，-0.008458）。

种子2额外改善2EBE E47（D→Y，-0.379910）及4PT4 L10（P→M，-0.040611），才使平均regret转为下降。这些是现有代理任务下的选择变化，不是实验突变效用，也不证明该位点所有候选结构更好。特别是2EBE选择改善与该蛋白几何退化同时存在。

## 判读与后续边界

本次定位支持三个分开结论：

1. 未训练噪声下退化更集中，但仅两枚噪声不足以确证单噪声监督的因果作用。
2. 末端阈值跨越和多原子严重碰撞同时存在，不能统一解释成手性边界小扰动。
3. 训练净通过数掩盖了已失败结构的进一步退化；监督teacher本身也存在严重几何问题。

因此保留当前模型作固定基线，不扩rank、不延长训练、不调整检查阈值、不删除2ED6/2EBE/2FKZ。若准备下一项干预，优先锁定跨噪声结构监督对照，而非扩大容量：固定模型、数据、总候选曝光、优化器，仅改变训练噪声覆盖，并同时报告训练/新噪声以及原已失败输出的错误数量和连续量。它是后续待验证问题，不是本轮已经证明有效的修复；本次没有启动。
