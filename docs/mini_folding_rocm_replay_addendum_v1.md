# ROCm 参数梯度标志重放补充审计

原1820份预测已经全部完成；原协议128份训练/评估坐标逐位相同检查失败，不修改旧协议、
代码、坐标或失败记录。全128份最大差0.000120640 Å，只有4份逐位一致。
首次失败1QY7、weak、seed600001的8次有界干预发现：两个输入加载路径的张量哈希相同；
在no_grad下，288个训练参数requires_grad=False精确复现评估，True精确复现训练探针，
每种状态两次forward均逐位一致。未改变权重，无优化器更新。尚未归因到具体算子。

在运行完整补充审计前锁定：两组全部TRAIN32×2噪声，每例False/True各一次，共256次
额外诊断NFE。每臂回到其原训练GCD0/2；使用同一个冻结终点checkpoint与原缓存，
逐参数核对训练权重，非训练参数保持public值；同一输入只改变梯度标志。
False必须逐位等于已完成的评估坐标，True必须逐位等于训练时坐标；失败保留，不调整
容差、不换卡重跑、不改变终点或噪声。no_grad下无backward、无权重更新。

该审计认证匹配运行状态的重放，不把原跨状态逐位检查改判为通过。
描述性评分使用已经完成的requires_grad=False坐标。另量化128例差异对GT质量、
严重碰撞和所检手性的影响。若补充审计成功，结果可支持解释旧检查的运行状态不匹配；
不自动证明某个kernel有bug、完整Jacobian正确、其他硬件也相同或部署通过。
