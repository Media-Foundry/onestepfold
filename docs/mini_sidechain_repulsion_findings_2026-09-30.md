# 侧链拟合联合排斥：保留精度收益，局部继续条件通过

2026-09-30，DiamondHill。**在固定骨架和残基位姿下，单一联合目标保留了大部分
纯拟合精度收益，同时降低碰撞负担，通过事前局部筛选。** 这是允许进入下一次
有界终点比较的证据，不是完整化学、一步可微输出或部署放行。

本轮按[冻结协议](mini_sidechain_repulsion_v1.md)只运行14次新局部拟合，未追加
目标系数、迭代预算、独立验证集或模型训练。旧纯MSE版本的失败记录不变。

## 1. 实际干预

复用七条蛋白、噪声12345/54321的原始C4/S1预测及整套理想参考局部构造；3CR6
继续保留两枚噪声的不支持来源槽位。仍从原始局部构造的零角度启动，不从上一轮
拟合终点续跑。N/CA/C/O/OXT和每残基平移、旋转均固定，只更新合法侧链桥键角。

唯一新目标是：

```
侧链到raw的MSE
+ Σ max(penetration−1.5, 0)² / (0.25 × 全部原子数)
+ 当前最坏16对的 mean[(max(penetration−1.9, 0)/0.1)²]
```

排斥形状和归一化沿用既有联合几何目标，系数固定1，无rho递增、权重或top-k
搜索。当前实验检验整个目标组合，不能区分哪一个子项独立贡献了多少收益。

优化中的排斥仅包含在合法侧链扭转下可能改变距离的原子对。若某允许旋转能把
一端归入旋转侧、另一端归入固定侧，且都不是该轴端点，则纳入候选；对全部允许
旋转取并集。同一刚体侧或轴端点相关恒距对排除。这里是结构性支持集合，不保证
当前角度下导数非零。所有原子对仍参与最终几何评分，未删掉固定碰撞来改善分数。

## 3. 剩余22对中21对是本阶段的恒距对

| 当前自由度分类 | 初始严重碰撞 | 联合拟合后 |
|---|---:|---:|
| 可变距离支持集合 | 16 | **1** |
| 全部允许扭转下距离恒定 | 21 | **21** |
| 全量总数 | 37 | **22** |

本轮“恒距”比上一轮“两端均标为不可动原子”更严格，还包括转轴端点及同一刚体
片段形成的不变距离，故不能把本轮21与上一轮20当成评分改变后的增减。
原全量碰撞定义、原子拓扑和排除规则未变。排除对初末距离最大差7.11e−15 Å。

唯一仍严重的可变对在3IE9/12345：残基1的C与残基5的CG1，最终距离约0.81320 Å，
穿透2.58680 Å。它说明有限权重惩罚与本预算没有保证每个可变碰撞都消失；不据此
单独调该例权重。全批最坏2.76991 Å来自恒距集合，并非优化器已将所有可动对
推到同一验收线。

所以，这个局部阶段不能独立完成几何修复。要处理恒距残留和链连接，下一阶段
仍需要允许残基位姿共同调整。本轮没有新联合终点，不能用0.815629直接声称
改进了既有联合求解的0.816197。两者输出阶段不同。

## 4. 成本、实际预算与验证

两个CPU FP64 worker、每个一线程；无新GPU模型调用。14份中13份达到60次迭代，
4B9P/54321为51次；closure62–91次。平均6.78秒、中位5.68秒（3.14–13.22秒），
最高RSS887148 KiB（约0.85 GiB）。包含本批审计及旧14份纯拟合复算的流水线
97.48秒，退出0，当前无运行任务。

配置仍是`max_iter=60,max_eval=90`。4B9P/54321实测91次closure已保留；实际
PyTorch2.12.0a0实现在线搜索返回后累计并检查函数评估数，不能把配置值写成每次
closure调用前执行的硬截断。源码路径、哈希和计数位置保存在
[预算核对](../reports/mini_sidechain_repulsion_2026-09-30/lbfgs_budget_audit.json)。没有追加
优化循环，51次迭代也不应解释为收敛；该例终态目标梯度范数约0.0277。

目标各项的14例均值：raw侧链MSE0.53743→0.28237，平均排斥0.01079→0.00277，
尾部项3.67251→0.38736，总目标4.22073→0.67249。MSE和组合目标分别记录，
不把组合目标下降当作全部坐标误差下降。

- 独立NumPy位姿重放最大差5.33e−15 Å，指标差4.44e−16；
- 逐残基键长/键角不变量误差4.44e−15，排斥及总目标复算误差3.55e−15；
- 独立重建可变距离支持集合，并核对全部排除对距离不变；
- 14份旧纯拟合产物重新审计通过；另用新代码关闭排斥重放旧case0，坐标逐位
  一致、60次迭代/63次closure一致；这是一份默认路径重放，不是14份重跑；
- 七项本地测试通过，含随机角度下恒距支持、轴端点、公式与局部导数；
- 146个归档成员、1,548,199字节逐项校验，六份运行源码与本地一致。

构造/化学元数据仍共享，不宣称独立化学解析器；局部惩罚导数检查也不是贯穿
