# C4/S1 DiamondHill 配对终点评价 v1

在新终点评价前冻结。两组训练均已结束；TRAIN32 曲线已可见，不用于选择终点、
修改方法或挑噪声。只评价各自 update_2048，先独立审计8192条历史、参数与优化器状态。

主比较 strong−weak，在同一 DiamondHill ROCm 环境重新计算两组各455蛋白×2噪声，
合计1820份坐标。原128 TRAIN、新增295 TRAIN、已观察过的DEV32分别报告。
成员、8个长度均衡分片、TRAIN600001/600011和DEV810013/810029不变。
DEV32是开发集，不称为新的独立确认集。历史CUDA模型仅保留在历史报告作背景；
不重算其5460份坐标或把跨平台对比归因于权重。

复用原生未修改的evaluate_diffusion_learning推理、checkpoint加载、GT评分、
cohort统计与结构尺度分析。public工程参照显式使用既有1YBK ROCm诊断输出，
建立单独probe_cache，原CUDA缓存不改。每个worker有7次工程调用，共56次，
检查public重放、加载前一致性、终点重复加载与未训练参数保持。
所有128份两臂终点TRAIN32坐标必须逐位重放，否则保留失败、不放宽精度界限。

8 GCD每卡一个worker；无自动重试、选卡择优、额外训练或checkpoint选择。
预测全部成功后，8个单线程CPU进程复算实验GT的AA/Cα-lDDT，独立dense距离核验；
继续计算全链RMSD、远距离误差、按蛋白均值后的10000次bootstrap、配对尾部、
严重碰撞、所检手性与新增失败。范围外失败或运行失败保留完整455分母，不能删例。
两组全部原子映射、实验观测mask相同。teacher预测不作为实验GT。

单步部署契约仍为C4/S1/K1，无后处理、无BindCraft；cached ESM2/C4推理时间
不代表端到端折叠延迟。本批没有新的通过阈值或自动晋升规则，联合审视结构精度、
全局误差与几何取舍后再决定下一步。
