# S2显著纠正2B0A失败；S5几何更好，但不是统一精度赢家

本批完成并收口。相同conditioning和初始噪声下，2B0A的两份严重失败原始S1输出，
在S2/S5中都变成高精度、零严重碰撞、所检手性全部正确的输出。它说明这些失败
有可用的预训练多步参照；不能继续仅围绕原S1附近的小幅几何调整解释或修复它们。
对照2Z0J的S2仍有严重碰撞，S5才清零。此结果不等于多步全面化学正确，更不等于
已经获得一步修正器或可微设计效用。

## 固定了哪些条件

[事前协议](mini_failure_step_reference_v1.md)选择2B0A失败例及源顺序第一条2Z0J对照，
各两噪声400009/400031。这是看过失败后选取的诊断集，不是独立验证或发生率估计。
在DiamondHill两张MI250 GCD并行，每蛋白共享原生FP32的ESM2-3B和四轮Pairformer
conditioning。权重、原子图、身份绑定初始噪声、无dropout/额外噪声/刚体增强均相同。
没有几何修正或训练，GT仅在推理后评分；没有best-of筛选。

每枚噪声先验证S1与c6a1d98f来源归档逐位相同，然后运行S2/S5。四份S1重放全部通过，
每次采样的conditioning/noise哈希及CPU/GPU RNG保持不变；每蛋白PF4次、diffusion16次。
实际GPU FP32调度为：

- S1：[2560, 0]
- S2：[2560, 55.97478485, 0]
- S5：[2560, 704.56433105, 144.69450378, 18.64899826, 1.01703489, 0]

这是同一确定性Euler规则下改变积分调度与NFE，不是原生随机S5，也不是从同一路径
截取第1/2/5个状态。结论限定于这套规则。

2Z0J的S2不是干净教师：400009残基8 CB–9 CD距离.9598 Å，400031残基8 CG2–9 CD
距离.8252 Å。第二噪声严重碰撞甚至由1增至2。S5在四例均通过既有基础绝对子项、
零严重碰撞和所检严格手性，但这些仍不是全面化学验证。

按照[评价v2](mini_evaluation_layers_v2.md)，不为raw预测虚构repair位移通过；
`legacy_joint_pass=null`。旧连接最大值（对S1分支）和当前最近分支残差分开保存。
例如纠正S1的错误cis分支后，相对旧分支的残差可能变大，不能因此说新分支更坏。
GT分支差异独立计数。2Z0J只有400031的S2仍有一处分支不一致，S5两噪声均一致。

类型化trans参考q95/q99的超限比例和残基位置全部保留；cis不套用这些参考带。
即使S5零严重碰撞，四例C–N绝对残差超过对应经验q99的连接仍有36、42、40、33处。
因此不能把基础检查通过写成全部连接符合实验分布；经验超限也不直接等同严重化学
错误。本批没有新设总通过阈值、角度严重阈值或精度非劣效容差。

## 对“原预测附近修正”的限制

后验描述性坐标比较发现：2B0A的S2相对S1，对齐Cα RMSD为5.0285、10.0995 Å；
未对齐Cα RMS为9.1758、13.9201 Å。它完成的是大范围结构纠正，不能解释成原1 Å
位移预算内的微调。对照2Z0J的对齐变化只有.2765、.1751 Å。

更直接地，在同一Cα集合的RMS度量下，三角不等式给出：若强制输出相对S1未对齐
Cα RMS≤1 Å，其对GT的最优刚体对齐RMSD不可能低于约4.0586、9.8798 Å。
这是由本批raw误差和原位移预算推得的限制，不是“附近没有几何可行解”的证明。
**原位移预算适合局部修复任务，却不能同时要求它纠正这两份S1的大尺度折叠误差。**
不在本批放宽预算；后续若做折叠纠正，应另立目标函数与验收。

## 方法判断与收口

1. 保留评价v2，不再让旧理想连接窗口独自否定方法；历史失败不改判。
2. 不再把这两份2B0A的全部问题交给“紧贴S1的几何投影”。多步原生模型提供了
   更准确、几何明显更好的结构参照，这是新的正面证据。
3. S2与S5各有取舍，不能未经几何检查就批量作为干净教师；当前只覆盖两蛋白两噪声。
4. 本批结束，不继续调这两条、追加修复网格或启动LoRA。下一训练方向若推进，
   应针对缺失的去噪纠正与化学有效性，用独立训练数据、实验GT锚及固定保留验证；
   不是修复已经收口的backward数值问题，也不是把最终部署改成S2/S5。

最终的一步输出、贯穿实际输出函数的序列梯度和硬设计效用仍未完成。
