# 一步折叠：恢复尾部与突破原生参考的执行计划

最终质量目标明确为**全原子 lDDT 0.90**，不是 Cα-lDDT 或预测置信度。使用同一原子范围、同残基排除规则、观测掩码、目标集合和 K=1 规则。均值达标而困难目标退化不算完成。原生参考全原子约0.820，因此能力保持最多是中间门槛，不能保证达到0.90。

## 0. 完成已经锁定的有限续训

保持累计16384更新主终点，HPC3 acd_u 的655518/655519运行中，不更改其源代码、loss或checkpoint选择规则。报告等更新与等8次曝光，后者明确不等算力。固定跟踪初始桥接的最差7条全原子目标，以及独立选出的最差7条Cα目标；同时报告重排尾部与所有128条逐目标变化，避免只挑坏例。两次噪声先按目标平均，不能best-of-K。

新增独立分析脚本 `scripts/report_pretrained_fixed_tail.py`，不修改训练。固定队列从初始桥接确定，而非最终续训结果；由于DEV已被使用，仍是探索性分析。组内bootstrap只描述已选尾部的变化，不能充当独立测试的置信区间。

## 1. 尾部根因审查与训练侧能力保持：优先级最高

若续训仍表现为均值改善、固定困难目标恶化，则结束“只加更新数”的路径。先核对完整TRAIN的分层探针（当前TRAIN32不够），困难DEV结构的链/构建体、缺失残基、局部距离与长程拓扑误差。检查每个loss的归一化和梯度是否偏向长链/原子多的目标。此审查不依据DEV坏例改变训练采样，也不把低分直接解释为容量不足或灾难性遗忘。

最小训练对照只有两臂：相同初始预训练ESMC桥接、TRAIN8192、GT目标、batch、噪声、种子和更新预算；A保持当前GT目标，B只加入训练侧原生教师局部距离保持项。从共同初始桥接开始，避免把已退化的终点当成唯一基线；如果预算/顺序不能完全复用已有A结果，重跑匹配A。先用4096更新作筛查，不能宣布收敛或普遍有效。

实现边界：

- 原生ESM2教师冻结，c1/s1/K1。只为TRAIN生成缓存，记录模型/序列/原子映射/采样/坐标哈希；一次生成供所有步骤复用。教师不进入部署，不为DEV提供训练标签。
- 第一版采用Cα局部距离，因已有Cα尾部退化证据，且避免侧链对称命名和全原子二次方成本。保留现有全原子GT监督。对观测到的Cα对、序列间隔至少3、GT或教师距离小于15Å取并集；所有mask与teacher target均detach。
- 项为每蛋白平均的Huber距离误差（β=1Å）。为避免强迫学生复制教师错误，教师与GT距离相差超过2Å的pair权重置零；记录保留比例及零有效pair目标，不能静默删除这些蛋白。半径/阈值是预声明工程候选，不是已验证最优值。
- 权重只用预先固定的TRAIN32、固定初始checkpoint校准：让辅助项的中位坐标梯度范数为GT项的10%，之后冻结一个λ。若零梯度/异常比例过高则预检失败，不用DEV选λ。记录原始和加权loss、坐标梯度及bridge/core梯度。
- 验证旋转平移不变性、未观测原子隔离、teacher无梯度、空pair损失为可微零、同一结构损失为零、学生梯度有限。最后验收一次trunk/一次structure、从保存checkpoint重放和独立CPU评分。

这测试的是特定GT一致局部距离保持，不是完整蒸馏或“解决遗忘”的证明。它可能只是重复GT信息；若改善无证据就停止，不扫大量权重。动态多噪声教师、hidden-state MSE、distogram和smooth-lDDT不在本轮同时加入。

## 2. 独立的接口容量对照

在能力保持对照完成后，或在其数据准备期间仅做实现预检，新增残差非线性bridge：

`h(x) = W0 x + b0 + Wup GELU(Wdown LN(x))`

预设宽度256，Wdown正常初始化，Wup及其bias置零；W0/b0从同一初始桥接复制。约增加41万参数，不改变449维核心接口。要分别在FP32/BF16验证初始投影及完整坐标与原模型一致。第一步Wdown梯度为零是零输出初始化的正常结果；Wup须有梯度，更新后再检查Wdown能获得梯度。不能把所有新增参数首步都有梯度设为错误验收要求。

实现时须新增独立优化器构造路径：当前 `configure_gt_optimizer` 明确断言bridge只有两个参数，不能直接把新模块替换进去后沿用。所有新参数需恰好注册一次，并确认核心冻结/更新策略与对照相同。旧源快照不修改。

两臂只有线性/残差非线性接口不同；同初始函数、同8192数据、同GT目标与训练预算。报告等更新及GPU时间、真实推理开销，不能以调用次数相同声称等计算量。

## 3. MLC是另一个变量，不能与非线性bridge捆绑

已有接触探针不构成端到端MLC证据。拟固定ESMC第12/24/36层，三层各1152维，缓存约为当前三倍，ESMC只前向一次。先验证layer36与现有final缓存的归一化、token与数值契约一致，不能仅凭维度替换。

实现优先采用 `W36 x36 + b + W12 x12 + W24 x24`（等价于线性concat投影），新增W12/W24置零，W36/b复制原桥接，以保持初始函数。与final-only单独配对，不同时加非线性分支或核心深度。抽取阶段只存所需三层，不缓存全37层。X570可用于已授权的抽取；HPC3 acd_u负责正式训练。MI250若使用，先做8GCD吞吐/精度预检，不直接跨硬件解释质量差异。

## 4. 门槛与停止规则

每阶段同时报告：AA/Cα/TM均值、重排最差5%、固定初始尾部、相对初始桥接和原生参考下降>0.05的比例、C–N/手性和后续完整化学检查。

筛查只有均值改善不算联合通过；尾部须有一致恢复证据，且不能以个别目标恢复代替全部尾部。候选确定后再做预先分层目标和独立训练种子重复，最后锁协议，冻结测试只用于确认。当前复用DEV不能验证全原子0.90的泛化目标。

若接口/保持均无收益，再分别测试结构Transformer8→12或Pairformer16→20，保持初始函数且一次调用，不能同时加深两者。Shortcut/consistency/MeanFlow属于后续独立训练方案，需显式时间参数化与导数/对齐正确性验证。当前不启动这些方法树。
