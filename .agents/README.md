# Persistent agent memory

This directory is the long-lived handoff for agents working on the project.

- `memory/project_context.md` records the current scientific scope and hard
  assumptions.
- `memory/decision_log.md` records dated decisions, evidence, and reversals.

Update these files when a literature check, data audit, or experiment changes
the project boundary. Keep implementation details in the repository docs and
code; keep durable reasoning here.
