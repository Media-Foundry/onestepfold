# Project Summary

## Goal
- OneStepFold is an open, MSA-free protein folding project.
- The active scientific target is an efficient all-heavy-atom protein monomer predictor, eventually using one Pairformer cycle and one structure evaluation.
- The active method question is now late-recycle refinement emulation, not MeanFlow or early-exit routing by default.

## Decisions
- Use PDB/mmCIF experimental coordinates as GT; UniProt/SIFTS are provenance and traceability only.
- Keep the universal GT schema multi-chain-aware, but use a monomer-first training view: exactly one generated protein chain instance, no nucleic-acid or other-polymer chain instances, primary X-ray/EM/neutron method, one coordinate model, length 20--1024.
- Preserve missing residues/atoms as masks; do not silently impute them. Keep modified residues and mask unmapped modified side chains.
- Store exact 100% sequence identity grouping only. Preserve near-identical constructs and small mutations; keep each exact group in one split.
- Authoritative SI implementation is Biopython `Bio.Align.PairwiseAligner`; exact SHA256 is only a lossless candidate index.
- Main sequence conditioner is frozen ESMC-600M final residue layer, with pinned model/code revisions and BF16 sharded safetensors. ESMC-300M is an ablation; ESM3 structure-track outputs are excluded.
- Official Protenix Mini-ESM remains a compatibility baseline, not the active ESMC model.
- Do not tune on `frozen_temporal_test`; use `temporal_dev_v1` for all method selection. Keep the 15-group strict low-homology set frozen.
- Do not claim thermodynamic truth, sequence-pretraining cleanliness, or novel early stopping. Report the declared PDB-label cutoff and ESMC contamination limitation.
- Teacher-pair jobs must run each shard in a private working directory because Protenix writes relative `./esm_embeddings`. Any logged per-target `Data error` must make the Slurm task fail.
